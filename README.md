# US LLC — usllc.online (Beta Preview Model)

Premium, high-contrast editorial corporate portal for **US LLC**, built to stage the upcoming full-spectrum suite of business formation services. Handcrafted by **SaaSSkul** ([saasskul.com](https://saasskul.com)).

Official Launch Scheduled for: **15th June, 2026**

---

## 🎨 Design Philosophy & Aesthetic
We implement an **Editorial Aesthetic** characterized by pairing high-caliber classic serif styles with clean Swiss sans-serif typography for maximum readability, balanced negative space, and modern high-end contrast:
- **Typography:** Display headings utilize elegant *Playfair Display* paired with beautiful *Lora* copy and clean computer-oriented *JetBrains Mono* for system states and dynamic rates.
- **Color Palette:** Royal Slate (`#0f172a`), Deep Indigo Space (`#1e2a4a`), and Vibrant Golden accents against clean, off-white, light gray canvases.

---

## ⚡ Key Features Included

1. **Bold Hero Media Player:**
   - Adapts on-the-fly to showcase high-definition company still images or streaming video formats.
   - Fully supports **YouTube embed players** and **Google Photos library** urls via a dynamic form integration block.

2. **LegalZoom-Inspired Service Explorer:**
   - Fully categorized vertical search tabs (Business Formation, Compliance & Agent, Intellectual Property protection, and Living Wills & Estate Trusts).
   - Dynamic search filters and clear interactive breakdowns explaining essential steps and fee estimates for each vertical.

3. **50-State Interactive Formation Calculator:**
   - Computes state-by-step Secretary of State filing fees and expected processing durations for all 50 US States.
   - Automatically computes optional structural addons like Professional Registered Agent representative, domestic EIN registry, or compliance alert filing systems.
   - Saves drafts configuration directly to standard client-side `localStorage`.

4. **Brand Protection & Trademark Clearance Simulator:**
   - Simulates Federal USPTO database queries with phonetic clearance clearances, suffix warnings, and diagnostic scores based on common legal criteria.

5. **Queries & Suggestion Ticket Subsystem:**
   - Stateful inquiry form storing tickets directly into a sandbox log.
   - Allows creators to clear individual tickets or wipe databases locally.

## 🛠 Tech Stack & Architecture
- **Framework:** React 18+ powered by **Vite**
- **Language:** TypeScript (Type-Safe configuration matrices)
- **Styling:** Tailwind CSS with responsive design targets
- **Icons:** Lucide React
- **Hosting Compatibility:** Fully pre-configured for seamless client-side single-page hosting on **Vercel** with zero backend infrastructure requirements.

## 🏃‍♂️ Getting Started (Development Setup)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
The server will boot up and bind to `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
The output assets will be rendered directly inside the `/dist` bundle directory.
